## Working with the cut

- Forage: search all 3,981 retrieved clips and add a result as A or B for the current shot. Queries search source titles, retained search terms, and inspected poster descriptions. Item searches broaden to individual words only when the complete combination has no match; the interface labels that fallback.
- Images: choose A (main image) and B (counter-image). Tap an image for its exact archive excerpt.
- Cut / collage: choose a composition; compare another shot; attach a local video; set its local in-point and speed. The soundtrack remains the suite audio.
- Shot duration: exchange time with the next shot while preserving chapter boundaries.
- Reading: see proposed cineosis, discriminators, book grounding and related shots.
- 45 signs: browse the periodic families. Opsign and sonsign are separate.
- Save / load: export/import an editable cut JSON. Local videos are not embedded in JSON and must be reattached. The MP4 does not update when you edit the browser cut.
- The attached WYGWYL_Forage_Cut.json is the default importable cut. WYGWYL_Forage_Catalogue.json preserves candidates, timecodes, queries, reviews, poem cues and references.
